# Lab 07 — заміри продуктивності

Це шаблон результатів, **не виміряні показники**. Заповнити після запуску 30-секундного профілювання в Chrome.

| Показник | До | Після |
|---|---|---|
| кадр p50 (мс) | не виміряно | не виміряно |
| кадр p95 (мс) | не виміряно | не виміряно |
| кадр p99 (мс) | не виміряно | не виміряно |
| паузи major GC | не виміряно | не виміряно |
| server tick p99 | не виміряно | не виміряно |

У DevTools → Performance записати 30 секунд, зберегти flame chart у `docs/flame-before.png` та `docs/flame-after.png`.
Результат `window.dogfightFrameStats()` у консолі Chrome показує p50/p95/p99.
Порівняння зробити на тій самій машині з 8 ботами й однаковими налаштуваннями.

Web Worker: експеримент треба виконати та порівняти витрати на передавання даних; рішення не прийнято без замірів.
