# Network experiment notes

Записуй під час локального тесту в двох вікнах:

- затримку: DevTools → Network → Throttling, порівняй RTT і вік snapshot;
- розбіжність: подивись на поле correction після руху або при затримці;
- чити: клієнт передає тільки input, тому підміна координат не є частиною протоколу;
- інтерполяцію: зараз 100 мс; збільшення робить рух віддалених кораблів плавнішим, але додає видиме запізнення.

GIF має бути записаний із реального запуску: два вікна браузера, одна кімната, рух/постріли та видимий netgraph. Не підміняй його ілюстрацією.
